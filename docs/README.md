# ExamNexus Documentation

ExamNexus is a dynamic examination resource orchestration platform for planning, allocating, validating, and managing examination resources.

This documentation covers the implemented architecture, workflows, intelligent assistance, development setup, and verification evidence.

## Documentation Roadmap

### 1. [Project Overview](project-overview.md)

Introduces ExamNexus, the problem it addresses, core workflows, user roles, capabilities, and technology stack.

### 2. [System Architecture](system-architecture.md)

Documents the frontend, backend, database, service architecture, domain entities, allocation pipeline, security, and system interactions.

### 3. [Features and Workflows](features-and-workflows.md)

Describes the implemented examination-management features and workflows from planning and registration through allocation, validation, approval, publication, and reporting.

### 4. [AI and Intelligent Orchestration](ai-and-intelligent-orchestration.md)

Explains requirement understanding, natural-language queries, explainability, and dynamic reallocation while keeping critical decisions under deterministic validation and administrator control.

### 5. [Development Setup](development-setup.md)

Provides prerequisites, environment configuration, backend/frontend setup, database configuration, commands, and local development workflow.

### 6. [Testing and Verification](testing-and-verification.md)

Documents automated testing, feature-level verification, regression coverage, and current verification results.

## Documentation Principle

This documentation describes the **implemented system**, not planned functionality.

Features, workflows, architectural decisions, and intelligent capabilities are documented only when supported by the current source code, tests, or other project evidence.
